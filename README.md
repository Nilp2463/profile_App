# Developer Portfolio App

A modern Flutter portfolio application showcasing developer profile, projects, and technical skills.

## Features

- Profile Dashboard
- Projects Section
- Skills Section
- Bottom Navigation Bar
- Add Project Functionality
- Clean UI Design

## Technologies Used

- Flutter
- Dart
